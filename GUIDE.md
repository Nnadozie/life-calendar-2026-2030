# GUIDE — when you feel lost

A short operating manual for the bad weeks. Keep it open when the calendar looks like a wall.

## The one rule

**Do the next smallest real thing.** Not the whole week. The next single action that is
expandable in the app — open the form, send the email, run the set, make the commit.

## If you only have one hour today

1. Do the Critical Path item that is **due this week** — else the one with the nearest
   horizon date.
2. If nothing is due: violin 45 min (streak), then 1 LeetCode problem.
3. If you cannot face either: 20 min walk, then re-read this page.

## If you are behind

- **Behind on a gate?** Repair it before advancing. A missed gate compounds; a late date does not.
- **Behind on coursework?** Cut the elective ambition, protect the required courses, keep ≥ 9 units.
- **Behind on training?** Drop to the stated daily minimum for one week. Do not quit the streak.
- **Broken a streak?** Restart at the minimum today. Never miss twice.

## What NOT to do

- Do not add a second major commitment mid-term. One per term.
- Do not trade protected rest away twice in a row.
- Do not start a new tech stack while a sprint is unfinished.
- Do not optimise a plan you have not yet executed for two weeks.

## The minimum viable week

If everything falls apart, this week still counts:

- [ ] One Critical Path action (open/do the single next step)
- [ ] Violin 45 min × 5
- [ ] One training session × 3
- [ ] One LeetCode problem × 5
- [ ] One real commit pushed
- [ ] Personal time, taken

## If a week is genuinely wrong

The plan is a model, and models get corrected. Note it in the week's Notes field and tell the
planning agent — it is allowed to re-sequence, as long as the gates still hold.
